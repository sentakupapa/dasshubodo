# 年計表ダッシュボード

社内スタッフが各自で確認できる年計表（過去12ヶ月移動累計）ダッシュボードのWebアプリです。

## 機能

- CSVアップロードによる月次データの取り込み（`日付,系列,数値` または `date,series,value`）
- 系列（カテゴリ）ごとの年計（移動年計）を自動計算
- 系列を選択してグラフ・テーブルで推移を確認
- 同じ系列・年月のデータは再アップロードで上書き更新

年計とは、当月を含む過去12ヶ月の合計値を月次でプロットする手法で、季節変動を除いたトレンドを把握できます。

## 技術スタック

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- SQLite (better-sqlite3) — サーバー上の `data/app.db` にデータを永続化
- recharts（グラフ描画）
- papaparse（CSVパース）

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` でダッシュボードにアクセスできます。

## 本番運用

```bash
npm run build
npm run start
```

### データの永続化について

データは `data/app.db`（SQLiteファイル）に保存されます。

- 社内サーバーやDockerコンテナで運用する場合は、`data/` ディレクトリを永続ボリュームとしてマウントしてください。
- Vercelなどファイルシステムが揮発するサーバーレス環境ではデータが失われるため、そのまま利用しないでください（自社サーバーでのNode.js常時起動運用を想定しています）。

### アクセス制御について

現状は「社内ネットワーク内からのみアクセス可能」という前提で認証機能を実装していません。社外に公開する場合は、リバースプロキシ（Basic認証やVPN等）でのアクセス制限を追加してください。

## CSVフォーマット

| 列 | 説明 | 例 |
| --- | --- | --- |
| 日付 / date | 年月（`YYYY-MM`, `YYYY-MM-DD`, `YYYY/MM` 等） | `2024-01` |
| 系列 / series | データの分類名（商品名・部門名など） | `商品A` |
| 数値 / value | 当月の実績値 | `120000` |

サンプルCSVは `/upload` ページからダウンロードできます。

## 既知の注意事項

- 依存パッケージの `npm audit` で Next.js 関連の既存脆弱性がいくつか報告されています。社内ネットワーク限定利用を前提に最新の14.x系パッチ版を採用していますが、外部公開する場合はNext.jsのメジャーアップグレードを検討してください。
