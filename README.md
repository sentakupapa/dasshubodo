# 年計表ダッシュボード

社内スタッフが各自で確認できる、店舗別の年計表（会計年度8月〜7月の年間合計・前年比）ダッシュボードのWebアプリです。

## 機能

- Excel（.xlsx）アップロードによる月次実績データの取り込み
- 店舗を選択すると、その店舗の年計表を確認できる（全店舗を閲覧可能）
- 年計セクション:
  - 売上金額（本年・前年の月次推移＋前年比グラフ）
  - 商品点数（ワイシャツ／ズボン／ジャケット）
  - 利用数（アプリ／BD／ダイヤモンド）
  - 14項目 年計表（点数）
  - 加工 年計表（点数、本年のみ・対ドライ比）
- アップロードすると既存データは全件置き換え（差分更新ではない）
- 初回起動時、データが空であれば同梱の参考データを自動で取り込む

年計＝会計年度（8月始まり〜7月終わり）の12ヶ月合計値です。

## 技術スタック

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- SQLite (better-sqlite3) — サーバー上の `data/app.db` にデータを永続化
- recharts（グラフ描画）
- exceljs（Excelパース）

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` でダッシュボードにアクセスできます。

## 本番運用

```bash
npm run build
npm run start
```

### データの永続化について

データは `data/app.db`（SQLiteファイル）に保存されます。

- 社内サーバーやDockerコンテナで運用する場合は、`data/` ディレクトリを永続ボリュームとしてマウントしてください。
- Vercelなどファイルシステムが揮発するサーバーレス環境ではデータが失われるため、そのまま利用しないでください（自社サーバーでのNode.js常時起動運用を想定しています）。

### アクセス制御について

現状は「社内ネットワーク内からのみアクセス可能」という前提で認証機能を実装していません。社外に公開する場合は、リバースプロキシ（Basic認証やVPN等）でのアクセス制限を追加してください。

## Excelフォーマット

アップロードするExcelには次の4シートが必要です（シート名は固定）。

| シート名 | 内容 | 主な列 |
| --- | --- | --- |
| `店舗マスタ` | 店舗名の一覧 | 店舗名 |
| `元データ` | 店舗×月×項目の実績 | 店舗名, 年区分（本年／前年）, 月, 項目, 売上金額, 商品点数, 客数, 利用数 |
| `元データ_14項目` | 品目別点数の内訳 | 店舗名, 年区分, 月, （品目ごとの列） |
| `元データ_加工` | 加工サービス別点数（本年のみ） | 店舗名, 月, （加工項目ごとの列） |

`data/seed/store-data.xlsx` に同梱している参考データが、この形式の実例です。

### 今後のデータ更新について

現状はExcelの再アップロードでデータを更新する運用です。将来的にアプリ画面上から直接実績を入力できるようにする場合は、別途フォーム入力機能の追加を検討してください。
